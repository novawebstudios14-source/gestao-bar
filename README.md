# Controle do Bar — estrutura visual

Este repositório contém somente as telas, estilos e componentes do painel criado para o bar. Os produtos e mesas exibidos são fictícios. Os formulários mostram a interface, mas não salvam alterações.

Não há banco de dados, API, autenticação ou configuração de hospedagem neste projeto.

Para visualizar localmente, instale as dependências com `npm install` e execute `npm run dev`. Para conferir a compilação, use `npm run build`.
